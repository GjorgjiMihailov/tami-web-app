# Банкарски документи — фаза Б: план

**Режим:** инлајн. Ова е список за водење и за продолжување по прекин, не брифинг за
подагент — затоа носи патеки и редослед, не готов код.

**Спецификација:** `docs/superpowers/specs/2026-09-02-bank-documents-design.md`
**Гранка:** `bank-documents`, од `main` по фаза А
**Основна линија:** 1204 теста

## Ограничувања

- PHPUnit 12 со класи, не Pest. `test_` методи на англиски, пораки на македонски.
- `php artisan test` е скршен — `php -d memory_limit=1G vendor/bin/phpunit <патека>`.
  **Еден фајл додека работам. Целиот пакет еднаш, пред спојување, и прашај прво.**
- Никогаш `git add -A` — дрвото носи неследени УЈП PDF-ови.
- По Blade измена: `npm run build`.
- Миграциите мали, со кратки имиња на индекси — MySQL нè каснал трипати.

## Задачи

- [ ] **1. `Form743` модел + миграција.** `company_id`, `status` (`pending`/`filed`),
      `payer`, `amount`, `currency`, `payment_date`, `basis`, `filed_by`, `filed_at`,
      `uploaded_by`. Полињата од образецот nullable — празни се додека не се обработи.
      Полиморфна врска `documents()`. Фабрика. Тест: записот се создава и се фрла.

- [ ] **2. Качување од клиент.** Livewire екран за физичко лице: едно поле, еден фајл,
      создава `Form743` во `pending` без ниту едно поле од образецот. Го користи
      постоечкото качување од `DocumentManager`. Рута + мени („743 обрасци" излегува од
      наскоро). Тест: качување создава pending запис со прикачен фајл.

- [ ] **3. Работниот список.** Екран за админ/сметководител што ги прикажува
      **необработените од сите клиенти**, со име на клиент, датум на качување и врска до
      фајлот. Сопствена рута, надвор од профилот на клиент. Тест: список покажува задачи
      од два различни клиента.

- [ ] **4. Обработка.** Форма во задачата: плаќач, износ, девиза, датум, основ — сите
      задолжителни — и едно копче што ги зачувува и ја префрла во `filed` со `filed_by` и
      `filed_at`. Тест: празна форма не поминува; полна форма ја затвора задачата.

- [ ] **5. `BankStatement` модел + миграција.** `company_id`, банка, сметка, број, датум,
      девизен или денарски. Полиморфна врска. Фабрика. Тест.

- [ ] **6. Изводи: качување и список.** Екран за правно лице. Список подреден по сметка и
      број, **со ред што го покажува прекинот** кога број фали. Рута + мени
      („Банкарски документи" излегува од наскоро). Тест: низа со дупка ја пријавува,
      целосна низа молчи.

- [ ] **7. Пристап на серверско ниво.** 743 рутите само за физичко лице, изводите само за
      правно. По образецот на `EnsureLegalEntity`. Тест во **двете** насоки — забрането за
      погрешниот тип, дозволено за вистинскиот. Втората половина е таа што спречува брана
      што забранува сè.

- [ ] **8. Dashboard.** Трите „наскоро" плочки кај физичко лице добиваат бројки: примени,
      необработени, внесени. ДЛД останува неветен. Тест со познати податоци.

- [ ] **9. Затворање.** `npm run build`, цел пакет еднаш (**прашај пред тоа**), спецификацијата
      се дополнува ако нешто отстапило, спојување.

## По планот

Првиот вистински тест го прави корисникот: клиент качува 743, работниот список го фаќа,
обработката го затвора. Тоа е потврдата што ниту еден автоматски тест не ја дава.
