## Готчи/поуки
- shell `sed`/heredoc ги губи `\` во PHP `use` линии и стрингови — менувај преку Edit или PHP-скрипта (scratchpad).
- Во тест-класа не именувај помошен метод `component()` (судир со `TestCase`).
- `assertSeeInOrder` на Livewire со кирилица не е сигурен — мери со `viewData(...)`.
- Организаторот: текстот „Прокнижен" се совпаѓа со опцијата „Прокнижени" — тест што бара „Прокнижен" лажно поминува; бара се „Прокнижен · Отвори".
- `efaktura_status` по default е `not_sent`; `@js()` ги задржува кирилските букви, а наводниците ги прави `"`.
- Целата серија трае ~15 мин (`php artisan test` директно); не пуштај серија додека менуваш фајлови.
